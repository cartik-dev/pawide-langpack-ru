# Language Pack — Русский · Paw IDE

Официальный языковой пакет Paw IDE: **полный перевод интерфейса на русский язык**.
278 строк — все меню, диалоги, панели, сообщения и статус-бар.

## Установка

### Windows
1. Скачайте архив `langpack-ru-1.2.0.zip` со страницы [Releases](../../releases) и распакуйте его.
2. Скопируйте папку `langpack-ru` в каталог плагинов Paw IDE:
   `%APPDATA%\Paw\PawIDE\plugins\langpack-ru`
   (можно открыть готовую папку прямо из IDE: **Плагины → Открыть папку плагинов**).
3. Перезапустите Paw IDE.

Или просто запустите `install.bat` из корня репозитория — он скопирует всё сам.

### Linux
```bash
./install.sh
```
Плагин ставится в `$XDG_DATA_HOME/Paw/PawIDE/plugins/langpack-ru`
(по умолчанию `~/.local/share/Paw/PawIDE/plugins/langpack-ru`), затем перезапустите IDE.

### Проверка
Откройте боковую панель **Плагины** (`Ctrl+Shift+X`) — у «Language Pack — Русский»
должен появиться статус **активен**, а интерфейс переключится на русский сразу
после перезапуска.

## Как это работает

Языковой пакет — это скомпилированная таблица перевода Qt (`pawide_ru.qm`).
Paw IDE 1.2.0 загружает `plugin.json` из папки плагина и устанавливает
переводчик **до создания главного окна**, поэтому переведён весь интерфейс:
меню, вкладки, палитра команд, диалоги, панель «Запуск и отладка», каталог
плагинов, карточки проверки в песочнице и статус-бар.

Исходник перевода лежит в [`translations/pawide_ru.ts`](translations/pawide_ru.ts)
(формат Qt Linguist) — на его основе CI собирает `.qm` при релизе:

```bash
lupdate <исходники Paw IDE> -ts translations/pawide_ru.ts   # обновить строки
lrelease translations/pawide_ru.ts                          # собрать .qm
```
